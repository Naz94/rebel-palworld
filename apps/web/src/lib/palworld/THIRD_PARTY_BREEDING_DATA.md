# Palworld 1.0 breeding reference

The files `breeding-pals.v1.json`, `breeding-combos.v1.json`, and the core algorithm in `breeding-engine.ts` are adapted from [ICSharperNow/palworld-breeding-calculator](https://github.com/ICSharperNow/palworld-breeding-calculator), copyright 2026 ICSharperNow, under the MIT License.

The upstream project states that the roster, breeding ranks, priorities, eligibility flags, and special combinations were extracted from Palworld 1.0 game files. Palworld names and game data remain the property of Pocketpair, Inc.

Rebel keeps this snapshot versioned so future Palworld patches can be audited before replacing it.
